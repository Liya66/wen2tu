# Security Policy · 安全策略

wen2tu runs entirely in the browser and opens files from untrusted sources, so issues such as script injection through a crafted `.mind.json`, Markdown or OPML file are taken seriously.

Please report vulnerabilities privately via **GitHub → Security → Report a vulnerability** on this repository, not in a public issue. Include a sample file if possible. We aim to respond within a week.

请通过本仓库的 **Security → Report a vulnerability** 私下报告安全问题，不要发布在公开 Issue 中。
