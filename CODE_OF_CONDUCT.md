# Code of Conduct · 行为准则

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). 本项目遵循 [贡献者公约 2.1 版](https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/)。

In short: be respectful and welcoming, assume good intent, give and accept constructive feedback, and focus on what is best for the people who use wen2tu. Harassment, insults and personal attacks are not tolerated in any project space.

简而言之：尊重和欢迎每一个人，善意地理解他人，建设性地给出和接受反馈，以使用者的利益为重。任何项目空间内都不容许骚扰、侮辱和人身攻击。

To report unacceptable behaviour, contact the maintainers privately through the email on the maintainer's GitHub profile. Reports are handled confidentially. 如需举报不当行为，请通过维护者 GitHub 主页上的邮箱私下联系，我们会保密处理。
